component · CODING — code block (highlight.js; keep language class on <code>)

Put a filename/label tab on top. Language class drives highlighting (e.g. language-python).

binary_search.pypython
def binary_search(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2      # midpoint
        if a[mid] == target:
            return mid            # found
        elif a[mid] < target:
            lo = mid + 1          # search right half
        else:
            hi = mid - 1          # search left half
    return -1                     # not found

Reference code inline with code.inline, e.g. the loop invariant is a[lo..hi]. Tag complexity with a pill: time O(log n), space O(1) — and flag a bad one like O(n²).

component · CODING — algorithm walkthrough (numbered steps + gotchas)
⚙️ the algorithm, in words
  1. Keep a search window [lo, hi] over the sorted array.
  2. Probe the middle; halve the window toward the target each step.
  3. Stop when found, or when the window is empty (lo > hi).
⚠️ common bugs
  • Array must be sorted — else the halving logic is invalid.
  • (lo+hi)//2 can overflow in fixed-int languages → use lo + (hi-lo)//2.
  • Off-by-one: is the window [lo, hi] or [lo, hi)? Keep it consistent.
