Where Are We Coming From?

the discriminative mindset · Week 1 recap 🧠
🧠 the big picture, first

Everything we've built so far learns a mapping: feed it an input → it hands back an output. That's it!

This slide sets up why that's not enough for generative AI — so let's really get this "old world" before the flip happens 👇

1 the core setup

we're given a labelled dataset:

(x₁,y₁), (x₂,y₂), ..., (xₙ,yₙ)

🐱 x = input — image, text embedding, feature vector, time-series window... anything!
🏷️ y = label/target — a class ("cat") or a number (tomorrow's temperature)

🐱   🐶

two labelled examples — cat photo (x) paired with label "cat" (y), same for the dog

the model's job: learn Input x → Output y, written more precisely as
P(y | x)
"given that I've seen input x, what's the probability of each possible label y?"
worked example

x = an image →

  • P(cat | x)   ★ 0.85
  • P(dog | x) 0.10
  • P(horse | x) 0.05

→ model picks the highest → "cat" ✅

2 why "discriminative"?

they do NOT learn how the data was generated — only the boundary between classes.

🚪 the bouncer analogy: a bouncer checking IDs is great at "let in" vs "not let in" — but has zero clue how a driver's license is actually manufactured. that's discriminative learning: draw the decision boundary, don't worry about the generative process behind it.

👉 this matters because Week 2 onward flips this — generative models try to learn how the data was produced, so they can create brand-new data that looks real!

3 three families, same idea

same kind of problem (input → output), just applied to different data shapes:

tabular / vectors

MLP / Feedforward

fully connected, no loops — great for structured/vector data with no spatial or time relationship to exploit.

images

CNN

conv → pool, repeated, then flatten → dense → softmax. ends the same place as everyone: P(y|x).

sequences / time

RNN / LSTM / GRU

little loops = memory carried through time steps. essential when order matters (today's weather depends on yesterday's).

architecturebest forexample mapping
MLPtabular / vector datafeatures → class or number
CNNimages (grid data)image → class ("5" → "5")
RNN/LSTM/GRUsequences / time-seriespast readings → next prediction

all three learn P(y|x) — none of them generate x!

discriminative ≠ generative. the pivot starts next slide 🚀

  1. new image in, will a discriminative model classify it or generate a new one?
    classify what's in it, not generate
  2. P(y|x) vs P(x) — which is discriminative?
    P(y|x)
  3. why can't a cat/dog classifier draw a new cat?
    it never learned the underlying pixel-pattern distribution of "cat-like" images — only the boundary separating cats from dogs
